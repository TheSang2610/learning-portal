Learning Portal API — bản gọi thử. Nút Try it out ở đây gọi thẳng backend thật và đọc dữ liệu thật trong MongoDB.

Trang này nằm cùng nguồn với frontend, và mọi lời gọi đi qua proxy /api của Next sang backend — nên không dính CORS, và cookie phiên là cookie first-party y như khi dùng trang web.

Đăng nhập trước khi thử endpoint cần quyền: mở POST /api/users/login → Try it out → điền email và mật khẩu → Execute. Máy chủ đặt cookie, các lệnh sau tự dùng nó.

Bản tài liệu để đọc (không gọi thử): thesang2610.github.io/learning-portal-frontend

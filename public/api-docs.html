Learning Portal API — bản gọi thử. Mặc định Try it out bắn thẳng vào backend thật đang chạy trên Vercel, đọc dữ liệu thật trong MongoDB.

Muốn đổi đích thì dùng ô Servers ngay dưới đây — Swagger tự dựng nó từ danh sách máy chủ, không cần tải lại trang.

Endpoint cần quyền: mở POST /api/users/login → Try it out → điền email và mật khẩu → Execute. Máy chủ đặt cookie, các lệnh sau tự dùng nó. Gọi Vercel từ máy mình thì cookie đó là cookie bên thứ ba — Chrome và Safari có thể chặn, lúc đó chuyển sang máy chủ Máy này rồi đăng nhập lại.

# Logo trường đại học

Thư mục chứa logo các trường cho khu **Chia sẻ tài liệu**
(`/share-document/institution` và khung "Trường đại học" ở `/share-document`).

## Cách thêm logo

1. Đặt file vào thư mục này. Tên file: chữ thường không dấu, nối bằng gạch ngang.
   Ví dụ: `hoc-vien-cong-nghe-buu-chinh-vien-thong.png`.
2. Định dạng: `.png`, `.jpg`, `.svg` hoặc `.webp`. Nên dùng ảnh vuông, nền trong suốt, khoảng 64×64px trở lên.
3. Vào **Admin → Môn học tài liệu → Trường đại học**, bấm sửa trường đó và nhập đường dẫn:
   `/images/institution/<tên-file>`.

Có thể dùng link `https://...` thay cho file trong thư mục này.
Trường chưa có logo sẽ hiện biểu tượng toà nhà mặc định.
